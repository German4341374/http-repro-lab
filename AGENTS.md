# Contributor guidance

- Keep source code, comments, documentation, and commits in English.
- Treat every imported HTTP artifact as untrusted.
- Never execute imported cURL through a shell.
- Never add real credentials, production captures, or personal data.
- Add evidence-backed tests for security-sensitive behavior.
- Keep the CLI fully useful without PostgreSQL, Kubernetes, or Terraform.
- Use Conventional Commits and update `docs/project-status.md` when scope changes.
